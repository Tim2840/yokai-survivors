# 03 地形與地圖設計

> 版本 v0.1（2026-11-03）。數字為起始值（推測），M2 之後依試玩校準。

## 1. 為什麼要 3D 高低差與多種地形

使用者要求：有高低差、有水面、草地等地形；不同妖怪在不同地形有不同效果（例如河童在水上跑比較快）；每張地圖設計都不同。這是本作與 Brotato／吸血鬼倖存者類的主要差異（它們多為平面競技場），所以**地形不是背景，是玩法**：

- 玩家用地形選路線（河童沿河逃、赤鬼佔高地）。
- 敵人也被地形影響（人類在水裡、泥裡會變慢；弓手和陰陽師會爬到高處）。
- 地圖要素的位置與地形搭配（結界石放在高台上特別強）。

## 2. 地形種類（共 8 種）

每個格子（地形圖的 1×1 公尺）屬於一種地形。**地形的效果 = 對所有單位的基礎效果 × 各妖怪的個別倍率**。

| id | 名稱 | 外觀 | 對所有單位（含人類） | 備註 |
|---|---|---|---|---|
| `grass` | 草地 | 淺綠，風吹草搖 | 無 | 預設地形 |
| `shallow` | 淺水 | 半透明水面、腳邊漣漪 | 移動速度 −20% | 可行走；水深 ≤ 0.4 公尺 |
| `deep` | 深水 | 深藍 | 人類不可進入；妖怪視種類（河童可，其餘不可） | 是阻擋人類的「天然牆」 |
| `mud` | 泥濘／沼澤 | 暗褐有氣泡 | 移動速度 −30% | 人類被拖得最慘，給遠程妖怪機會 |
| `rock` | 岩地 | 灰色碎岩 | 無 | 與高低差搭配，常見於山地圖 |
| `bamboo` | 竹林地 | 竹子（障礙）＋落葉地 | 視線遮蔽：遠程單位射程 −30% | 竹子是碰撞體 |
| `stone` | 石階／神社石畳 | 規整石板 | 移動速度 +5% | 規則的階梯，是高低差的主要載體 |
| `spring` | 溫泉 | 白霧、水氣 | 站著每秒回復 1% 最大生命（玩家方）；人類不受影響 | 稀少，一張圖最多 1～2 池 |

高低差不是地形種類而是**另一層屬性**：每格有高度 `h`（公尺）。規則見第 5 節。

## 3. 各妖怪的地形效果矩陣

數字 = 該妖怪站在該地形上的**乘數**（與上表「對所有單位」相乘）。★ 是特色格（要讓玩家感覺得到）。

| 地形 | 提燈小僧 | 河童 | 赤鬼 |
|---|---|---|---|
| 草地 | 1.0 | 1.0 | 1.0 |
| 淺水 | 移速 ×1.0（不受減速）；鬼火範圍 −10%（水氣） | ★ 移速 ×1.45 並每秒回復 1% 生命；水盤傷害 +15% | 移速再 ×0.85（笨重），護甲 −2 |
| 深水 | 不可進入 | ★ 可進入；移速 ×1.6、水中隱身（敵人鎖定範圍縮小 50%）；陸地回復為 ×1.0 但**離水太久（> 6 秒）會「乾」：攻擊力 −15%，回到水邊解除** | 不可進入 |
| 泥濘 | 移速不再額外減；光圈內敵人 −10% 移速（疊加） | 移速 ×0.9（比別人好一點） | ★ 不受泥濘減速（力氣大）；金棒震波範圍 +20% |
| 岩地 | 無 | 無 | ★ 護甲 +2、金棒傷害 +10% |
| 竹林地 | ★ 鬼火不被視線遮蔽影響（燈光穿過竹林），範圍 +15% | 無 | 無（竹子是碰撞體，赤鬼可砍倒 1 根/次，見備註） |
| 石階 | 無 | 移速 ×0.95 | 移速 ×1.05 |
| 溫泉 | 回復效果 ×1.5 | 回復效果 ×1.5 | 回復效果 ×1.5，另外怒氣緩降 |

備註：
- 赤鬼金棒的震波可以破壞「竹子（阻擋物）」，開出新路。
- 河童的「乾」機制是為了避免他整局待在水裡太強（水中速度 + 隱身）；也讓地圖上水的分佈有意義：水域離越遠，河童越吃虧。
- 提燈小僧的地形特色較弱（他是均衡型），補償在「光圈」機制：夜裡的地圖有「暗區」，光圈內敵人看得見玩家前會被減速（細節 docs/04）。
- **新妖怪（天狗、雪女、狐火…）的地形矩陣在收集系統確定後再加**（docs/14 Q5），先預留：天狗＝高台＋風；雪女＝雪地（第 6 張以後地圖）＋水變冰；狐火＝草地與竹林夜間。

## 4. 高低差規則

- 地形高度 `h` 在 0～6 公尺之間，緩坡（坡度 ≤ 35°）可直接走，陡坡（> 35°）視為牆。
- **上坡**：移動速度 ×0.85（對所有單位）；**下坡**：移動速度 ×1.1。
- **高台優勢**：站在比目標高 ≥ 1.5 公尺的位置，遠程單位射程 +15%（玩家方與人類通用）。這個 +15% 也用來讓「弓手上高台」成為威脅。
- 領頭妖怪跳不起來（不增加按鈕）；所有高低差都要有可走的斜坡或階梯。**不做「懸空平台要用跳的才上得去」。**
- 子彈與範圍攻擊不受高低差影響水平距離（用 2D 距離判定，高度只影響視覺與高台射程加成），避免打不到在斜坡上的敵人。
- 地圖要素放置在 `h` 變化平緩處（高度差 ≤ 0.5 公尺內）。

## 5. 地圖資料格式（給 `src/data/maps/*.ts`）

每張地圖是**一份資料**，不寫死在程式裡：

```ts
interface MapDef {
  id: string;                // 'village-field'
  name: string;              // i18n key
  seed: number;              // 預設地形生成種子（每局可換）
  size: { w: number; d: number };      // 公尺，例如 40 × 40
  heightFn: string;          // 高度生成函式 id（見 src/world/heightFns.ts）
  terrainRules: TerrainRule[];   // 依高度、噪聲、距離決定地形種類
  props: PropRule[];         // 樹、石燈籠、田埂等（有碰撞的標明）
  playerStart: { x: number; z: number };
  enemySpawn: { ring: number };     // 在玩家周圍半徑 ring 公尺外圍生成；不在深水
  elementWeights: Record<ElementId, number>;  // 該圖的地圖要素權重
  modifier?: MapModifier;    // 該圖獨有的機制（見第 6 節各圖）
  waveSet: string;           // 人類波次表 id（見 docs/04）
  boss: string;
  palette: string;           // 天空、霧、光照設定
  unlock: Unlock;
}
```

## 6. 五張首發地圖

每張圖的設計目標：**路線不同、機制不同、玩起來要有不同的決策**。尺寸 40×40～60×60 公尺（比原型的 30×30 大，因為要有高低差與地形可以逛）。

### 6.1 夜之村田野（教學圖，M3 做）

- 主題：月夜下的稻田與村外小徑，人類是一般村民。
- 地形：大片草地；稻田區（淺水＋田埂）、一條小溪（淺水、有一段深水）、一座土坡（高 2 公尺，緩坡，頂上有石燈籠）。
- 機制：**無特殊機制**，讓玩家理解基本玩法。
- 要素權重：石地藏、詛咒祭壇、神籤較多（容易理解）。
- 人類：村人、足輕為主，第 12 波起加僧兵。
- 頭目：**退魔僧（小頭目）**。
- 解鎖：初始。

### 6.2 河童之淵（M6）

- 主題：山谷河流與瀑布潭，河童的主場。
- 地形：中央一條彎曲河流（深水＋淺水），兩岸草地與岩地，上游有瀑布高台（高 4 公尺）。
- 機制：**漲潮**——每 3 波水位上升 0.4 公尺（淺水擴大、深水變多），河岸的泥灘會被淹沒；河童越來越強，其他妖怪被擠上岸。
- 要素權重：結界石、狐面商較多。
- 人類：弓手（在岸邊對你射）、足輕、河邊的漁民（腳程快、血少）。
- 頭目：**獵河武士**。
- 解鎖：通關夜之村田野。

### 6.3 竹林迷徑（M6）

- 主題：霧中的竹林與小徑，視線不好。
- 地形：竹林地為主，夾雜窄徑（石階）、泥濘窪地、一座小神社（高台）。
- 機制：**濃霧**——視野半徑 14 公尺，之外敵人看不見（但敵人看得見你，火把會暴露他們位置）；竹子是碰撞體，能被赤鬼破壞。
- 要素權重：神籤、荒塚較多。
- 人類：火把兵（在霧中顯得是「光點」，很美）、忍者風「探子」（速度快，閃躲高，血少）。
- 頭目：**竹林山伏**。
- 解鎖：通關夜之村田野。

### 6.4 山寺石階（M7）

- 主題：山腰的古寺，層層石階。
- 地形：階梯式高低差（共 4 層，每層 1.5 公尺）、岩地、石階為主；溫泉一處。
- 機制：**居高臨下**——上層持續有僧兵與陰陽師把守，從上往下進攻；玩家站在高處射程 +15%（全圖通用規則）但敵人也是；鐘樓的鐘每 5 波響一次，吸引一批敵人往鐘樓聚集。
- 要素權重：結界石（放高處特別強）、御神木、太鼓。
- 人類：僧兵、陰陽師、弓手（在上層）。
- 頭目：**大僧正**。
- 解鎖：通關河童之淵或竹林迷徑任一。

### 6.5 荒城（首發最後一張，M7）

- 主題：廢棄的城，護城河與城牆。
- 地形：外圍護城河（深水）、石橋（窄，成為人類的瓶頸）、城牆（陡坡，視為牆）、內庭石畳、城樓（高 5 公尺）。
- 機制：**砲擊**——城牆上的大砲每隔幾秒對地面預告落點（紅圈 2 秒）後轟炸，傷害玩家與人類（人類也會被炸，可以利用）。
- 要素權重：全種類平均。
- 人類：全部種類，混合更密集。
- 頭目：**退魔大師**（二型態，docs/04）。
- 解鎖：通關山寺石階。

### 6.6 地圖設計的共通限制

- **高物件限制**：鏡頭固定在斜上方約 50°，玩家周圍 10 公尺內不應有高度 > 2.5 公尺且不可穿透的物件（會遮住玩家）。竹子、樹以「細幹＋高處淡出」處理，或者放在畫面上緣側。原型階段要先做視覺驗證（M1 的鏡頭測試），**不採用「挖空」或「遮擋物透明」的做法**（沿用燈落之境的規則）。
- 每張圖的「安全區」：玩家出生點周圍 6 公尺不生成要素、敵人。
- 每張圖要有至少 2 條「繞圈路線」，讓玩家能邊走邊打（風箏）。
- 每張圖都要能用種子換佈局的小細節（樹、石頭位置），但**地形骨架固定**（確保平衡可預測）。

## 7. 地形與地圖的技術要點

- 地形用 `PlaneGeometry` 細分（約 1 公尺 1 格 × 4 頂點）+ 高度圖，頂點色混合草、岩、泥；水面是獨立的半透明網格，高度 = 該區水位。
- 地形查詢 `terrainAt(x, z) → { h, type }` 是熱路徑：預先烘焙成 `Uint8Array` 地形種類圖 + `Float32Array` 高度圖，O(1) 取值，不在每幀重算。
- 單位的高度 = `terrainAt(x,z).h`（貼地，坡度平滑），不做真實物理。
- 水面波動用著色器（時間先 `% 2π`，`pow` 底數 clamp）。
- 碰撞：固定障礙物用格子圖（`Uint8Array` 阻擋圖），單位之間用空間雜湊。
