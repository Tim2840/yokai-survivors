## 3. 你（新 session）的第一個任務：開工報告

先不要寫程式。依序做：

1. 讀 `CLAUDE.md`、`docs/01`～`docs/14`（至少完整讀 01、02、03、05、06、14）。
2. 跑 `npm install`、`npm run typecheck`、`npm test`，確認起始套件是綠的；如果不是，先修並回報。
3. **審查文件**：找出矛盾、遺漏、不可行、數字明顯有問題的地方。至少檢查：
   - docs/02 的目標戰力曲線（第 10 節）與卡片、要素的數值是否能互相對上（例如：第 20 波要 350 DPS，卡片＋小妖＋要素的上限能否到）。
   - docs/03 的地形矩陣是否有「某隻妖怪在某張圖完全沒有特色」或「某地形組合太強」。
   - docs/05 的時程是否合理（每個里程碑的交付物是否塞太多）。
   - docs/14 的待決定問題是否還有遺漏的。
4. 向使用者**報告**（用繁體中文，見下面的格式），並等使用者回答 docs/14 的 Q1、Q2、Q3、Q6（其他有建議值可先採用）。
5. 使用者點頭後，把答案移到 docs/14 的「已決定」，升 GDD 版本（v0.2），**才開始 M0**。
