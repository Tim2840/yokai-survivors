# 20 設計把關：我（AI）替你守的項目

> 2026-11-09，使用者：「每次都要請你研究蠻累的，我也不是專業遊戲設計師，我是獨自一個人設計的，我需要你幫我把關更多項目，輔助我有效率且正確地設計出商業等級且創新、有趣的遊戲」。
> **這份是我的工作說明書**：以後你只要丟想法，**我主動做研究與審查**，你只需要回答我列出的 1～3 個「要你拍板的事」。
> 誠實聲明：我能做的是研究、檢查一致性、挑毛病、提方案、寫程式與測試；我**沒辦法取代真人試玩**（手感、有不有趣），也沒辦法替你做市場與商業的最終決定。下面凡是「我的判斷」都標明，不是業界定論。

## 1. 工作方式：你丟想法 → 我交「設計審查卡」

你提任何新想法（或我自己發現問題）時，我**不先動手**（除非你說「做」），先交這張卡，**不用你提供研究**：

| 欄位 | 內容 |
|---|---|
| ① 一句話結論 | 做／改了再做／不做，一句話 |
| ② 這件事在解決什麼 | 對應哪條設計支柱（docs/01 第 2 節）、哪個玩家問題 |
| ③ 同類遊戲怎麼做 | 有來源附連結；沒查到就明講「沒查到，以下是推論」 |
| ④ 和既有決定的衝突 | 對照 docs/14 的已決定區；有衝突列出來交你選，**不自己推翻** |
| ⑤ 影響哪些系統、工作量、風險 | 範圍膨脹、效能、平衡、新手門檻、測試成本 |
| ⑥ 舉一反三 | 對照 docs/19：每隻角色／每種武器／每個共用畫面會不會怪 |
| ⑦ 商業等級檢查 | 對照第 3 節的面向，這件事讓哪一面變好或變差 |
| ⑧ 我的建議＋替代方案 | 一個推薦，最多兩個替代 |
| ⑨ 要你拍板的事 | **最多 3 件**，每件附我的預設選擇（你說「照你的」就照做） |

我另外**主動**做的事（不用你叫）：
1. **每次回報前自我審查**（CLAUDE.md「合理性自我審查」5 點）。
2. **每個里程碑結束時交一份「商業等級體檢」**（第 3 節的表更新分數）。
3. **發現你的想法會壓過另一個決定、或讓範圍失控時，先講**，不是做完才講。
4. **有「你可能不知道但該知道」的事就主動說**：例如上架要準備什麼、同類遊戲玩家最常罵什麼、法規與平台規定（我查得到的就附來源，查不到就標待查證）。

## 2. 設計支柱（做決定時回來看；來源 docs/01、docs/13）

1. 爽快的割草，但有「選擇」。2. 妖怪不同、地形不同、地圖不同。3. 高風險高報酬的地圖要素。4. 局外成長是「選項變多」多於「數字變大」。5. 和風、圓潤、可愛又帶一點詭異。
**我的判斷：這五條裡真正有「差異化」的是 2（地形＋角色）、3（要素）和題材（妖怪當主角）**；其餘是類型標配。所以資源要優先花在這幾處。

**整體判斷**：玩法層（核心循環、技法、進化）已經在 4 分水準；**拉低整體的是「第一印象與外圍」**——新手引導、打擊感、音樂、設定畫面、留存、商店頁。這些都不是玩法，但商業品質看的就是這些。建議之後的優先順序：**①手感一輪 ②新手引導 ③設定畫面 ④小地圖（已排）⑤留存與圖鑑**，其餘玩法內容（赤鬼、更多地圖）和它們交錯做。

## 4. 「創新」的機會（我的判斷，待你選；沒有查證市場上有沒有人做過，之後要查才能宣稱「首創」）

同類遊戲很擠（docs/13：Steam 單年上百款），**光有妖怪皮不夠**。本作已經有、而且別人少做的組合是：
1. **高低差地形＋每隻妖怪不同的地形效果**（大多同類是平地競技場）。**機會**：讓地形不只是背景——例如「高處的要素更肥」（D54 已做）、河童的水路、赤鬼能砸碎岩石。我建議**把地形玩法當成最重要的賣點，再多設計 2～3 個「只有這個遊戲有」的地形互動**。
2. **要素的風險報酬**（試煉碑、祭壇、山頂神社）。**機會**：把要素做成「每一局的地圖故事」（這一局誰先出現、要不要貪）。
3. **人類是「來驅妖的」**（敵方有個性、有立場）。**機會**：敵人與頭目的台詞、行為差異，現在人類比較單一。
4. **妖怪的收集與百鬼夜行**（小妖）：目前還沒做，是最能長期留人的設計。
**我的判斷**：創新不在「再加一個機制」，而在把 1～3 做到「別人一玩就說這遊戲有地形戲」。這比再加技法有價值。
