# 16 收集、抽卡與活動系統：研究、評估與排程（2026-11-05）

> 起因：使用者想加入「抽卡」與其他活動系統，讓玩家有收集的感覺，並問有沒有更有儀式感的做法。**使用者 2026-11-05 決定照建議做、抽卡只放外觀（docs/14 D32）**；Q5（新妖怪怎麼收集）一併定案為降伏儀式。
> 資料限制同 docs/15：wiki 原文讀不到，來源是搜尋摘要與攻略，都是二手資料。

## 1. 同類遊戲怎麼做

| 遊戲 | 收集的方式 | 儀式感從哪裡來 |
|---|---|---|
| **HoloCure**（最接近「抽卡」的同類） | 遊戲內金幣（只能玩出來）每抽 1,000；依團體分卡池；抽到重複 → 角色小幅加成（約 +1%，有上限）並可能附送服裝；每次重複給 1 顆「賭徒之淚」，**7 顆換指定角色、15 顆換服裝**（保底），淚只能用在同一個卡池（[wiki.gg](https://holocure.wiki.gg/wiki/Character_Gacha)、[Techraptor](https://Techraptor.net/gaming/guides/holocure-gacha-guide)） | 抽的動畫；重複也有用；保底讓人不會白花 |
| **吸血鬼倖存者** | 條件解鎖：做到某件事就解鎖角色、武器、地圖；解鎖跳出提示與音效；失敗的局也算進度（[Cyberpost](https://cyberpost.co/?p=1816)、[Loop & Ledger](https://loopandledger.beehiiv.com/p/the-overlooked-but-humble-magic-sauce-of-vampire-survivors)） | 每一局結束都有東西解鎖；學者認為它借用了賭博心理（[The Conversation](https://theconversation.com/vampire-survivors-how-developers-used-gambling-psychology-to-create-a-bafta-winning-game-203613)） |
| **Megabonk** | 任務當主要進度：達成條件 → 再用銀幣「買」解鎖（兩步）；任務也解鎖欄位（[Pro Game Guides](https://progameguides.com/megabonk/how-to-unlock-all-characters-in-megabonk/)） | 目標清單看得到 |
| **黑帝斯** | 命運清單（成就式，**要回大廳手動領獎**）、典籍、送禮換信物（[Screen Rant](https://screenrant.com/hades-unlock-fated-list-minor-prophecies-guide/)、[Hades Wiki](https://hades.fandom.com/wiki/Fated_List_of_Minor_Prophecies/Hades_II)） | 「領獎」這個動作本身；和角色的關係 |
| **Balatro** | 收集冊（Collection）列出每張牌與解鎖條件，條件綁定玩法（[games.gg](https://games.gg/zh-Hant/balatro/guides/balatro-全要素解鎖指南/)） | 一眼看到「還差什麼」 |

## 2. 法規與風險（抽卡）

- **台灣**：2023-01-08 起，「網路連線遊戲服務定型化契約」要求**付費**的機會中獎商品揭露中獎機率、獎項與稀有數量並加警語，違者可罰 3～30 萬（[TechNews](https://technews.tw/2022/07/30/mgames-items-probability-laws/)、[彰化縣消保宣導](https://town.chcg.gov.tw/files/53_20230105154846882_112年1月份消費者保護宣導.pdf)）。
- **歐洲**：比利時把付費開箱視為賭博（2025 安特衛普法院判決），荷蘭與歐盟層級也在討論禁止；有些遊戲因此在當地關掉開箱（[Promise Legal](https://blog.promise.legal/loot-box-laws-game-developers/)、[PC Gamer](https://pcgamer.com/the-netherlands-moves-toward-an-outright-loot-box-ban)）。
- **結論**：**抽卡只能用「玩出來的」貨幣（功德），永遠不賣**。這樣就不是付費機會中獎，網頁優先（D17）上架 itch.io 或之後上 Steam 都不會碰到開箱法規。**即使不付費也照樣公開機率與保底**（玩家信任、也方便之後改成付費時不用重做）。

## 3. 評估：純抽卡 vs. 更有儀式感的做法

**純抽卡的問題**：①新妖怪是玩法核心，靠運氣抽到會讓人覺得「卡關」；②我們沒有付費，抽卡唯一的作用是「花功德的期待感」，但功德同時要買修行（局外成長），會互相搶；③要大量可抽的東西（服裝、外觀），美術量很大。

**更有儀式感、又和題材契合的做法**（建議組合）：

1. **百鬼帖（收集冊，核心）**：所有妖怪、小妖、人類、頭目、地圖要素、法具、招式變化、大招、聯動都有一頁；沒解鎖的顯示剪影與**解鎖條件**（Balatro 式，目標看得到）；第一次遇到／做到就「入帖」。
2. **降伏儀式（新妖怪的取得方式，回應 Q5）**：在指定地圖達成條件（例：竹林迷徑撐過頭目）→ 結算畫面出現該妖怪 → **用毛筆把名字寫進百鬼帖**的演出（墨跡、印章、音效）→ 下一局可選。條件解鎖（VS 式）＋演出儀式，不靠運氣。
3. **御朱印帳（印章收集）**：每張地圖、每個頭目、夜深度、特殊挑戰各有一枚「御朱印」（日本寺社真的有這個文化）；**蓋章要回神社手動領取**（黑帝斯式領獎的儀式感），集滿一頁給獎勵。
4. **百鬼御籤（抽卡，用遊戲內貨幣；D32：只放外觀）**：在神社搖籤筒的演出；**獎池只放外觀與小加成**（燈籠紋樣、妖怪配色、小妖的造型、百鬼帖的裝飾），**不放妖怪本體**；重複給「緣」，**集 N 個緣換指定獎品**（HoloCure 的淚）；公開機率。
5. **活動**（單機網頁，不需要伺服器）：
   - **今夜的試煉（每日挑戰）**：用日期當種子、固定的妖怪與要素、一兩個特殊規則；成績存在本機（沒有排行榜伺服器）。
   - **時令祭（依真實月份的季節活動）**：節分、七夕、盂蘭盆、月見、年末…在那段期間地圖換裝、有限定御朱印與御籤獎品；**活動結束後保留在「回憶」裡、明年再回來**，不用 FOMO（錯過就永遠拿不到）逼人。

## 4. 建議

- **採用 1＋2＋3 當收集的主體**（儀式感最強、和題材最契合、不靠運氣卡核心內容），**4 抽卡只放外觀與小加成**，**5 活動在上線前後再加**。
- 功德的去處要重新規劃：修行（成長）與御籤（外觀）分開計價，避免互搶；或御籤用另一種只從活動／印章拿到的「香油錢」。
