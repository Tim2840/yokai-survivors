# 23 美術第一輪：現況、問題、建議排程（設計審查卡）

> 2026-11-09，使用者：「美術方面何時改善？」。**這份是評估與排程，尚未實作**（等你說「開始」才動工）。格式依 docs/20。
> 誠實聲明：**畫面好不好看，最後只有你能判斷**；我能做的是量剪影與對比、檢查一致性、把程式化能做到的天花板做滿（docs/08 第 7 節）。以下「同類遊戲」沒有新查來源，凡是同類比較都是推論。

## 現況（看今天的截圖，我的判斷）
- 角色：提燈小僧、河童、村人、足輕、弓手都是**程式組的圓潤造型＋頂點色**，沒有描邊、沒有臉（表情）、動作只有彈跳。剪影還行，但**質感一致、缺少「精緻感」**。
- 場景：**單色草地＋假圓形陰影**，沒有地表變化（草叢、花、碎石、泥痕）、沒有天空與遠景、沒有真陰影、光影單調；高低差靠顏色分，氣氛（霧、光束、粒子）很少。
- 特效：命中、擊殺爆圈（D69）、水盤、鬼火有；整體色彩統一度還可以（`palette.fx`）。
- UI：功能性的，缺少統一的和風視覺語言（邊框、紙質感、印章、字體）。
- 計畫中的位置：**M2b「風格基準」**（docs/05 第 2.2 節，音樂也在那一階段），目前排在 M2-3 與 E-2 之後，約 W11–W12。

## 這件事在解決什麼
支柱 5（和風、圓潤、可愛又帶一點詭異）還沒有被看見；商業等級體檢（docs/20 第 3 節）「第一印象與外圍」是拉低整體的項目，美術是其中最直接的一項。

## 和既有決定的衝突（要你選）
1. **docs/05 第 2.2 節的原則是「先定水準、再複製」**：新角色（赤鬼）和新敵人（E-2 的四種）都該在風格基準之後做，否則做完還要整批重做。**但目前排程是 赤鬼 → E-2 → … → M2b。這兩件互相矛盾**——要嘛提前美術，要嘛接受赤鬼與 E-2 的模型之後重做。
2. 「不使用外部模型檔」（CLAUDE.md）＋ D44「Blender 試做」：Blender 版提燈小僧只在 M2b 做一隻試看，**不影響這張卡**，除非你想提前決定。

## 舉一反三
- 描邊、表情、動作是「**所有角色共用**」的系統，要做成資料驅動（每隻角色給參數），不要寫死在提燈小僧上；赤鬼之後才進來時直接套用。
- 場景氣氛要對**每張地圖**有主題參數（高地、竹林、水邊…），不要只調高地。
- 河童的水、提燈的火：特效顏色已經分開（`palette.fx`），環境光不能把它們洗成同色。

## 商業等級檢查
美術目前 docs/20 記 3 分（我今天重看截圖，場景單調、角色沒描邊，覺得偏高，個人判斷 2.5～3）；做完 A＋B 我預期到 3.5（仍然是程式化天花板內；到 4 以上需要外部素材或 Blender）。**其他面不變差**，只有「手機效能」要盯。

## 我的建議
**插一個「美術第一輪」（A＋B，約 6～8 天）在 E-1 之後、赤鬼之前**（C 併入圖示 A，音樂不動）。理由：赤鬼、E-2 的模型就能直接用新風格做，不會做兩次；E-1 的足輕與弓手剛做完，是最好的套用對象。
替代 1：**照現在的順序**（赤鬼 → E-2 → M2b）：不延遲內容，但赤鬼與 E-2 的模型之後會重做，總工作量多約 2 天。
替代 2：**只做 A（環境氣氛，3～4 天）**：最快看到「畫面變好」，角色精緻度留到 M2b。

## 要你拍板的事
