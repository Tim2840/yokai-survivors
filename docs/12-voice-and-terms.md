# 12 用詞與口氣

> 版本 v0.1（2026-11-03）。從燈落之境的 `docs/12-voice-guide.md` 精簡搬來（第 5.2、5.3 節原樣搬，規則整理後搬）。**寫任何玩家看得到的字之前先讀這份。**

## 1. 三種文字，三種口氣

| 種類 | 例 | 口氣 |
|---|---|---|
| **系統文字**（按鈕、能力值名、提示、錯誤、商店） | 「選一張卡」「功德不足」 | 清楚直接，用遊戲用語沒關係（HP、傷害、冷卻） |
| **卡片與要素說明** | 「攻擊力 +6%」 | 一行、數字放前面或最後固定位置、單位一致 |
| **敘事字幕與圖鑑小故事** | 民俗故事、地圖名卡 | 短句，帶一點古風與詩意，不說教；每則 30～60 字 |

人類沒有台詞；妖怪沒有台詞（先不做劇情）。**若之後加台詞，一律先給使用者看草稿、點頭後才寫進程式。**

## 2. 通用規則

- 每句 ≤ 36 字、一句一件事。
- 同一個東西在畫面、文件、程式註解叫法一致（第 4 節固定名稱）。
- 數字格式：百分比寫 `+6%`；小數一位；單位放後面（`3 公尺`、`0.5 /秒`）。
- 卡片說明用「動詞＋對象＋數字」：「提升攻擊力 6%」。
- 不用大陸用語、不用簡體（第 3 節）；不用兒化音。
- 日本題材的名詞用**台灣常見的寫法**：妖怪、鬼火、鳥居、神社、陰陽師、僧兵、足輕、河童、天狗、雪女。需要標讀音時用括號放日文假名（只在圖鑑）。
- 民俗小故事要註明靈感來源（傳說名稱），不照抄現代作品或他人整理的文字。

## 3. 台灣用語（第 5.2 節，原樣搬）

影片、品質、資訊、網路、軟體、硬體、資料、螢幕、滑鼠、列印、智慧、預設、設定、啟用、連結、檔案、載入、介面、使用者／玩家、點選、最佳化／調整、伺服器、程式。

禁用清單（寫進 `tests/unit/voice.test.ts`）：視頻、質量（指品質時）、信息、網絡、軟件、硬件、數據、屏幕、鼠標、打印、智能、默認、設置、激活、鏈接、文件（指檔案時）、加載、界面、用戶、優化。

### 3.1 口語（第 5.3 節，原樣搬）

| 不要 | 改成 | 備註 |
|---|---|---|
| 這兒、那兒、哪兒（兒化音） | 這裡、那裡、哪裡（或這邊、那邊） | 「一會兒」台灣也常用，可以留 |
| 踏實 | 安心、穩穩的 | |
| 凳子 | 板凳、椅子 | |
| 歇口氣、歇歇 | 休息一下、坐一下 | |
| 咱、咱們 | 我們 | |
| 啥、咋、甭 | 什麼、怎麼、不用 | |
| 挺（挺好） | 蠻、滿、很、還滿 | |
| 犯困 | 好睏、想睡 | |
| 外頭 | 外面 | |
| 扔、胳膊 | 丟、手臂 | |
| 聞著、看著（「V 著就…」） | 聞起來、看起來 | |
| 瞧 | 看 | |

做法：每寫完一句，用這張表掃一遍；拿不準就換成最白話、最像台灣人平常講話的說法；**使用者改過的句子是標準答案**。

## 4. 固定名稱（畫面、文件、程式註解一律這樣叫）

| 東西 | 叫法 | 不要用 |
|---|---|---|
| 玩家扮演的 | 妖怪（領頭妖怪） | 英雄、角色 |
| 跟隨的小隊員 | 小妖 | 寵物、召喚物、隨從（文件內部可用「隨從」，畫面用「小妖」） |
| 敵方 | 人類（個別叫村人、足輕、僧兵、陰陽師、弓手、探子） | 怪物、敵人（系統文字可用「敵人」） |
| 經驗 | 魂火 | 經驗值、EXP |
| 局外貨幣 | 功德 | 金幣、點數 |
| 稀有度 | 凡／良／珍／極 | 普通／稀有／史詩／傳說（畫面上） |
| 生命、攻擊力、範圍等數值 | 能力值（畫面上「能力」） | 屬性（D35：「屬性」專指五行） |
| 金木水火土 | 屬性（五行） | 元素 |
| 怪、妖、鬼、神 | 種族 | 類型、屬性 |
| 升級卡 | 卡片（「選一張卡」） | 技能卡 |
| 通用道具（所有妖怪共用） | 多重（一次多發幾發）、碎裂（命中時飛出碎片）、穿透、廣域、力量…；**名稱不帶特定角色或武器的字**（鬼火、狐火、燈籠、水盤、金棒）。角色專屬的字只用在主武器、技法與大招（使用者 2026-11-06） | 鬼火增殖、碎火（舊名） |
| 技法分類（所有妖怪共用，D64） | **連鎖系**（命中後延伸出去：分裂、彈跳、歸巢…）、**近身系**（貼著身體運作：繞身、護身、前導…）、**佈置系**（把效果放在場上：地面、種子、柱子…）；**依「怎麼運作」命名，不依屬性或材質**（燃燒、火焰、水、金屬都不行）。取捨道具「狂熱」（舊名狂燈）同理。介面與 HUD 的通用句子也不寫「鬼火」，用「技法」「發射數」。`tests/unit/genericTerms.test.ts` 全掃（使用者 2026-11-09） | 燃燒系、分裂系、環繞系（舊名）、狂燈、鬼火 +N 顆 |
| 保留給之後角色的名稱 | 九尾、九尾狐（使用者 2026-11-06：之後要開發九尾狐角色） | 技法、道具、大招、要素的名字都不要用 |
| 地圖上的特殊物 | 地圖要素（畫面上叫各自的名字） | 神龕、機關、道具 |
| 兩波之間 | 整備 | 商店（避免誤會）、休息 |
| 局外商店 | 神社（分頁：修行、卡池、秘術、圖鑑） | 商店、升級 |
| 號令 | 號令（主動技能） | 大招、終極技 |
| 難度分級 | 夜深度 | 難度、等級 |
| 要素名 | 詛咒祭壇、賽錢箱、神籤、狐面商、太鼓、結界石、石地藏、荒塚、御神木 | |
| 地形 | 草地、淺水、深水、泥濘、岩地、竹林地、石階、溫泉 | |

## 5. 介面文字長度

英文比中文長 2～3 倍：按鈕與卡片版面要能撐開；中文版本先寫短。每個字串在 i18n 表裡可以帶 `maxLen` 提示，過長由單元測試警告。
