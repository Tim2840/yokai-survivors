## 驗證

- `scripts/packed/prepare.sh`＋`check.mjs`：實際打包、檢查通過；故意讓舊伺服器送別的檔，會自動換埠（5181 → 5182）。
- `scripts/shots/helpers.mjs`：實際跑「升到 12 級 → 跳到 4:00 → 截圖」，包圍圈有出現、沒有卡住。
- skill 本身是說明文件，沒有跑正式的「有 skill／沒 skill」對照測試（要開多個子代理，成本高）；之後如果發現某個 skill 沒被叫到或寫得不清楚，直接改那份 SKILL.md。
